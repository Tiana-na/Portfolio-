# אתר הפורטפוליו של טיאנה פולקנפולק

אתר סטטי (HTML/CSS/JS) — 3 עמודים: `index.html` (בית + עבודות), `about.html` (מי אני), `contact.html` (צור קשר).

## איך מעלים ל-GitHub Pages

1. יוצרים ריפו חדש ב-GitHub (Public).
2. מעלים את כל התוכן של התיקייה הזו לריפו (כולל התיקיות `css/`, `js/`, `assets/`).
3. בהגדרות הריפו → **Settings → Pages** → תחת "Branch" בוחרים `main` ותיקיית `/root` → Save.
4. תוך דקה מקבלים לינק חי בפורמט `https://<username>.github.io/<repo-name>/`.

## איך מעלים ל-Netlify (חלופה מהירה)

גוררים את כל תיקיית `portfolio` לעמוד ההעלאה ב-[netlify.com](https://app.netlify.com) — האתר עולה תוך שניות.

## הוספת אנליטיקס (מעקב תנועה)

בקובץ `index.html` יש הערה בתוך `<head>` שמסמנת איפה להדביק את קוד המעקב של Microsoft Clarity ו/או Google Analytics (GA4). מומלץ להעתיק את אותו קוד ל-`<head>` בשני העמודים הנוספים כדי לעקוב אחרי כל האתר.

## "הסצנה שאחרי" (Easter egg)

בפוטר של כל עמוד מוסתרת אינטראקציה קטנה בהשראת סצנות פוסט-קרדיטס של מארוול:
- **דסקטופ:** קומבינציית חצים במקלדת — למעלה, למעלה, למטה, למטה, שמאלה, ימינה, שמאלה, ימינה.
- **מובייל/טאצ':** אותה קומבינציה בהחלקות אצבע (swipe) באותו כיוון.

בהצלחה נחשף בעדינות משפט קטן מתחת לפוטר, עם קישור לעמוד יצירת הקשר. הטקסט ניתן לעריכה בקלות בתוך `class="stinger-text"` בכל קובץ HTML.
